# kompbez

Небольшой одностраничный сайт-помощник по криптографии.

## Что реализовано
- **Раздел 1:** шифр Хилла над `Z33` с матрицами `A` и `B`, кнопками шифрования/расшифрования и подробным решением по блокам в формате векторов-столбцов (с поэлементными произведениями и суммами).
- **Раздел 2:** решение задачи про перестановочный шифр с магическим квадратом порядка 4, где можно менять исходные переменные:
  - ввод известных переменных вида `a12=3, a21=5, ...`,
  - ввод шифртекста `Y`,
  - ввод текста для шифрования,
  - поиск всех подходящих ключей, расшифрование и шифрование.

## Запуск
Откройте `index.html` в браузере.
