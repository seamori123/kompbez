# kompbez

Небольшой одностраничный сайт-помощник для работы с шифром Хилла над `Z33`.

## Что реализовано
- Ввод матрицы `A` (квадратная) и матрицы `B` (вектор-столбец `n×1`).
- Ввод текста на русском алфавите (33 буквы).
- Кнопки **«Зашифровать»** и **«Расшифровать»**.
- Подробный вывод шагов вычислений по блокам и итогового результата.

## Запуск
Откройте `index.html` в браузере.
